# Interview preparation

**Business question:** Which teams and ticket priorities struggle to meet illustrative resolution SLAs?

**Short explanation:** I worked on an AI-assisted educational analytics project that generates synthetic IT support tickets, validates them, loads them into SQLite, computes operational KPIs with pandas and SQL, and exports a static HTML dashboard.

Know how to explain:
1. Why SLA breaches are counted only among resolved tickets in this introductory model.
2. What a SQL JOIN to the SLA-policy dimension adds.
3. Why we use a deterministic random seed.
4. The difference between a real business deployment and a simulated portfolio project.
5. How to reproduce the report using the README commands.

Be transparent that synthetic results are not real employer outcomes and that this is an AI-assisted learning project.
